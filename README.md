# 象棋·技能战

一个轻量级、高端的中国象棋网页游戏，包含全新的技能对战系统。

## 特性

- 🎮 完整的中国象棋规则实现
- ⚡ 全新技能系统（6种专属技能）
- 🎯 战前技能选择机制
- 🎨 高端深色主题设计（木质/墨水/金色调）
- 🎵 程序化生成的音效系统
- 📱 响应式设计，支持移动设备
- 🔥 流畅的动画和微交互
- 🇨🇳 简体中文界面

## 游戏规则

### 基本规则

遵循传统中国象棋规则：
- 棋盘 9×10，包含楚河汉界
- 九宫格限制将帅和士的移动
- 相/象不能过河
- 马走日字但会被蹩
- 炮需要翻山才能吃子
- 兵/卒过河后可以横向移动

### 技能系统

**全新技能选择机制**：
- 游戏开始前，双方各选择一个技能带入本局
- 每个技能专属于一种棋子类型
- 红方先选，黑方后选
- 游戏中只能使用已选择的技能

**6种专属技能**：

1. **激光波** - 车专属
   - 消耗回合，摧毁车所在列南北所有棋子
   - 不能伤害任何一方的将帅
   - 每局只能使用一次

2. **自焚** - 炮专属
   - 炮正常移动吃子后，与落点3×3范围内所有棋子同归于尽
   - 不能伤害任何一方的将帅
   - 每局只能使用一次

3. **骑兵** - 马专属
   - 马跳上己方兵卒合体，获得马+兵的双重移动能力
   - 合体后显示"骑"标记
   - 每局只能使用一次

4. **替死** - 士专属
   - 消耗回合激活，该士不再受九宫限制
   - 当己方将帅被吃时，敌人会改为吃掉此士
   - 激活后显示"替"标记
   - 每局只能使用一次

5. **不屈** - 象专属
   - 消耗回合，复活上回合死亡的象并摧毁占据者
   - 不能摧毁将帅，每局只能使用一次

6. **吞噬** - 兵专属
   - 选中后必须用兵吃掉敌方非兵棋子
   - 全体己方兵获得被吃棋子的移动能力
   - 每局只能使用一次

## 技术栈

- **框架**: Vite + React + TypeScript
- **样式**: 原生 CSS (无额外依赖)
- **音效**: Web Audio API (程序化生成)
- **打包大小**: 极小（无大型依赖库）

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

应用将在 http://localhost:5173 启动（或其他可用端口）

### 构建生产版本

```bash
npm run build
```

构建产物位于 `dist` 目录

### 预览生产版本

```bash
npm run preview
```

## 开发说明

游戏采用函数式编程风格，核心逻辑与 UI 分离：

- `game/rules.ts`: 包含所有象棋规则验证
- `game/skills.ts`: 全新技能系统的独立实现
- `utils/sounds.ts`: 使用 Web Audio API 生成音效，无需音频文件

## 游戏流程

1. 标题界面 → 点击开始
2. 技能选择 → 红方选择一个技能 → 黑方选择一个技能
3. 开始对局 → 使用选定的技能进行对战
4. 游戏结束 → 再来一局或返回主菜单
